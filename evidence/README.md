# 실행 증거

이 문서는 최신 검증의 진입점입니다. 과거 상태와 실패·검수 이력은 [날짜별 원문](records/2026-10-08.md)에 보존합니다. 아래 최신 실제 API 모델 검증과 이전 관측 연결·과제 시연 검증을 구분합니다.

## 실제 API 학습·예측·운영 연결 — 2026-10-08 최신

- 표준 Docker 이미지 `groundwatch-serving-app`의 격리 테스트 컨테이너에서 [백엔드 전체 로그](records/api-native-ops-tests.txt): 117개 실행, 116개 통과·실패 0·선택 TensorFlow smoke 1개 건너뜀. 실제 API 집중 테스트 18개에 중복 발행·정답 최초 수신·자동 감지/재학습/30일 평가/교체·guard 탈락·결측일·후보 로드 실패·재시도·복귀가 포함됩니다.
- 프론트 테스트 5개·TypeScript/Vite 빌드와 표준 Compose 빌드 성공은 직전 코드 검증 세션에서 확인했습니다. 8100 컨테이너 healthy, 25개 실제 API 모델 예측 준비·7단계·수집/확인/복귀 버튼·콘솔 오류 0건을 확인했습니다. [최신 HTTP 기록](records/api-native-ops-http.json) · [운영 화면](records/api-native-ops.png).
- 서울시 365일 수집 범위로 확대하고 별도 3개 특성 masked residual LSTM을 연결했습니다. 최신 지하수 관측은 2026-08-31, 노원구는 2026-07-31입니다. 25/25곳 예측 준비는 오늘 관측 확보나 현장 정확도 검증을 뜻하지 않습니다. 기존 22개 모델은 재사용했고, 부족/탈락했던 3개 관측소는 확대 자료로 준비했습니다. 25개 모두 동일한 365일로 새로 학습했다고 설명하지 않습니다.
- 종로구 현재 v2의 학습 정답 207개(2025-09-21~2026-04-15), 검증 69개(2026-04-16~06-23), 시험 69개(2026-06-24~08-31). 검증 RMSE 0.01355322, 시험 RMSE 0.03471781, 시험 persistence RMSE 0.03436799입니다. 초기 검증 게이트는 통과했지만 시험에서 persistence보다 개선됐다고 주장하지 않습니다. 단위는 API 원값입니다.
- 직전 코드 검증 세션에서 종로구 실제 수집 자료 365행을 운영 상태와 분리한 `/tmp/gw-native-validation`에 복제해 TensorFlow 30 epochs 후보 학습·MLflow 등록·29일 대기·30일 평가를 실행했습니다. 후보 RMSE 0.02117913, 기존 0.01180308로 개선 기준 실패, guard도 실패하여 기존 모델을 유지했습니다. 이는 격리 과거 자료 평가이며 운영 환경의 경보·모델 교체 발생 증거가 아닙니다.
- 최신 운영에서는 관측소별 발행 1건·수신 정답 0건입니다. 감시·재학습·평가 대기는 정상이며 시험 예측을 운영 정답으로 넣지 않습니다. 통과 후 새 모델 서빙과 복귀 분기는 격리 자동 테스트에서 검증했습니다. 실제 운영 교체 이력은 새 정답 도착 이후 별도로 확인해야 합니다.

- 운영 8100의 실제 API 재수집 작업이 완료됐고 errors는 비어 있습니다. 이어 25개 관측소 오차 감시 작업이 모두 checked로 완료됐습니다. 최신 유효일은 여전히 2026-08-31이며 종로구 발행 1건·수신 정답 0건으로 대기합니다. 새 관측 정답 수신·실제 운영 경보·교체가 발생했다고 설명하지 않습니다.
- 수위 단위와 강수 빈값은 공식 명세를 재조사했으나 단정 근거가 없어 기존 원값·null 보존 정책을 유지했습니다. 원천 링크와 확인 범위는 [데이터 설명](../data/README.md)에 기록했습니다. 발표 PDF는 별도 작업 범위로 이번 검수에서 제외했습니다.
