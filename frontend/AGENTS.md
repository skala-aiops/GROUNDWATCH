# 프론트엔드 작업 지침

저장소 공통 규칙은 [루트 AGENTS.md](../AGENTS.md)를 따릅니다. 작업 전에 [프론트엔드 README](README.md)와 [공통 API 계약](../docs/contracts.md)을 읽습니다.

## 변경 범위

- 컴포넌트·훅·전역 store·API·타입·유틸리티·디자인 시스템의 배치와 컨벤션은 README를 따릅니다. 진행 중인 구조를 완료된 아키텍처로 설명하지 않습니다.
- 요청 처리는 공통 API 클라이언트를 사용합니다. 서버 필드·단위·날짜·상태를 화면 편의로 바꾸지 않습니다. 변경 요청을 자동 재시도하지 않습니다.
- 실측·합성·저장 예측·추정 비교값을 라벨과 출처로 구분합니다. 예측 미준비·결측을 숫자 0이나 임의의 예측으로 채우지 않습니다.
- AIOps 화면에서 작업 접수·학습 완료·후보 평가·승격·실제 서빙을 구분합니다. UI 상태만으로 모델이 교체됐다고 표시하지 않습니다.

## 완료 확인

- `frontend/`에서 `npm test`와 `npm run build`를 실행하고 결과를 보고합니다.
- 선택·범위·날짜·상태 표시 변경은 관련 UI 흐름을 확인합니다. 3D 변경은 2D 대체 화면·모바일·동작 줄이기도 확인합니다.
- 모의 API를 쓰는 브라우저 테스트와 실제 화면→API→모델 확인은 구분합니다. E2E 파일·설정이 없으면 E2E 통과를 주장하지 않습니다.
- 생성된 dist·캐시·브라우저 보고서·인증 상태는 커밋하지 않습니다. 증거가 필요하면 키를 제거한 결과만 `evidence/` 기준에 맞춰 남깁니다.
