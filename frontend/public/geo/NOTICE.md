# Seoul map attribution

Source: https://github.com/southkorea/seoul-maps
File: kostat/2013/json/seoul_municipalities_geo_simple.json
Original data: KOSTAT census administrative divisions, 2013.
Repository contributor: Lucy Park.
Repository license: Apache License 2.0; accompanying LICENSE-2.0.txt is included.
Downloaded 2026-10-08. Geometry is unchanged. Districts match the API by Korean district name; the source's statistical codes are not API administrative codes.

These historical boundaries are a district selection aid, not a survey or current legal boundary guarantee. No station coordinates are inferred from district polygons. Vertical extrusion is constant and does not encode risk or groundwater level.
