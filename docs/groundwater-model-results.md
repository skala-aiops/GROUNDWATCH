# 서울 25개 구 지하수 LSTM 결과

사용자 제공 CSV와 GroundWatch 기획서를 기준으로 2026-10-07에 실행했다. 모델 학습·실제 API 추론을 완료했으며 운영용 성능이나 싱크홀 발생 확률을 검증한 결과는 아니다.

## 결과와 해석

- 25개 구, 구마다 1개 관측소, 총 25개 LSTM을 학습했다.
- 시간 분리 시험 예측 6,256건. 검증 기준 통과 17개, 시험에서 전날 값 유지 기준보다 RMSE가 작은 모델 15개다.
- 관측소별 시험 RMSE 중앙값은 4.405 cm다. 관측소별 기간·변동 폭이 달라 전체 자료를 합친 RMSE와 구분한다.
- 금천구 15.015 cm(기준선 2.851 cm), 종로구 21.175 cm(기준선 1.686 cm) 등 개선이 필요한 결과도 포함한다. 검증 통과가 미래 성능을 보장하지 않는다.
- 동작구 마지막 사용 구간은 2019-06-30, 종로구는 2018-07-29, 중랑구는 2018-12-19다. 다른 구도 대부분 2025년 자료다. 예측 대상일은 마지막 연속 관측 다음 날이며 현재 날짜 예측이 아니다.
- 자동 재학습·위험 판정 임계값·운영 승격은 미설정이다. 모두 연구용 후보이며 과거 자료 재현과 비교에 사용한다.

## 데이터 정제와 누수 방지

원본 604,840행, 관측소·날짜 고유 조합 544,672개, 추가 중복 60,168행이다. 값이 충돌하는 관측소·날짜 5,569개, 충돌 제거 후 0 이하 깊이 901개를 제외했다. 큰 수위 변화는 임의로 잘라내지 않아 센서 이상 가능성이 시험 오차에 남아 있다. 0 이하 값은 결측 표기 또는 피압수 여부의 추가 확인이 필요하다.

보간하거나 다른 관측소로 채우지 않았다. 20일 입력과 다음 날 정답이 모두 연속일 때만 학습한다. 관측종료 제외, 최소 120개 학습 창·41일 연속 구간을 요구하고 최근 사용 가능한 연속 구간과 자료량으로 선택했다. 시험 성능으로 관측소를 고르지 않았다.

시간 순서 학습/검증/시험 약 70/15/15 분리, 마지막 21일 시험 확보. 학습 구간으로 정규화하고 검증으로 조기 종료했다. 시험 입력은 각 예측일 이전에 알 수 있는 실제 관측이며 장기 다단계 예측은 아니다.

제공 코드의 LSTM 32→32→16, Dense 16→1 구조를 재사용했다. 전날 대비 깊이 변화량을 학습하고 API에서 마지막 실측 깊이를 더해 cm 단위로 복원한다.

단위 근거는 [서울시 보조관측망 조회표](https://swo.seoul.go.kr/ugrwtr/retrieveAsstnObsrDta.do)의 수위 gl.-m와 강수량 mm다. 원본 깊이 ×100 → cm, 강수량은 mm 유지(모델 내부 ×10). [서울 열린데이터광장 출처](https://data.seoul.go.kr/dataList/OA-15611/A/1/datasetView.do). 입력 CSV SHA-256은 manifest.json에 기록했다.

## 실제 연결 검증

- 25개 관측소 실제 HTTP 다음 날 예측과 과거 분석 25/25 성공. 모델 식별자, 자료 버전, 대상 날짜를 응답에서 확인했다.
- 최근 21건 RMSE를 API 실측·예측으로 독립 계산해 일치함을 확인했다. 임계값이 없어 판정은 not_evaluated다.
- 기존 회귀 검사 25건, 추가 정제·시간 분리·초기 복원 검사 5건, 프론트엔드 검사 10건을 통과했다. 호스트 HTTP 검사 3건은 소켓 권한 때문에 실행되지 않아 Docker 환경에서 다시 실행해 통과했다.
- 화면 관측소 선택·모델 평가 25행·과거 실측/예측 그래프·동일 예측 재요청을 확인했다. 모바일 384px, 데스크톱 1440px에서 가로 넘침 없이 표시했다.
- 실제 Compose 빌드·종료·재기동 후 25개 자료 ID·성공한 실행 기록·예측값이 정확히 보존되었다. 25개 MLflow candidate 버전과 FINISHED 학습 기록도 확인했다.

## 산출 파일

- district_model_metrics.csv: 구별 성능·학습 및 평가 기간·모델 식별자.
- heldout_predictions.csv: 분리 시험 6,256건의 실측·예측·전날 유지·오차.
- latest_forecasts.csv: 마지막 연속 관측 다음 날 예측 25건. 미래 실측이 없어 이 25건 자체의 정확도는 평가하지 않았다.
- manifest.json: 모델 입력·정규화·시간 분리·출처·등록 식별자.
- bundle.zip: 25개 Keras 모델과 정제 자료. 다른 환경에서 data/groundwater/bundle.zip에 두고 bundle.json과 함께 사용한다.

실행 방법은 [모델 안내](../serving_app/groundwater/README.md)를 참고한다. 커밋·푸시·공유 브랜치 병합은 수행하지 않았다.
