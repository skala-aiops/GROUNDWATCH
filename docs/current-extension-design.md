# 오늘 기준 과제용 자료 확장 설계

2026-10-08 사용자 요청으로 과거 자료의 날짜만 옮기는 시연 대신, 확보한 원관측 뒤부터 서울 오늘까지 합성 일별 자료를 추가합니다. 원본 관측 CSV와 기존 실제 자료 모델·평가를 보존합니다. 화면은 실제 달력으로 오늘 입력→내일 예측을 제공하며 작은 합성 자료 표시를 유지합니다. 최신 API 관측이 확보되었다고 설명하지 않습니다.

1. 기존 원본을 읽고 각 관측소의 마지막 실측 다음 날짜부터 생성합니다. 같은 관측소의 과거 월별 수위 분포·강수량 쌍을 고정 seed로 재표본화하고, 최근 실측 앵커에서 완만하게 계절 패턴으로 이어갑니다. 비어 있던 과거 관측일은 채우지 않습니다.
2. 별도 CSV에 모든 기존 값을 보존하고 `origin=observed/synthetic`를 추가합니다. 별도 manifest에 원본 해시, 관측소별 합성 시작일, 종료일, 생성식·seed를 기록합니다. 데이터셋 전체 `source_kind=synthetic`로 별도 모델 namespace를 사용합니다.
3. 시간 순서를 유지하여 최근 최대 730개 학습 target, 검증 60일, 테스트 60일, 이후 90일 재생을 분리합니다. scaler는 학습 구간에서만 계산합니다. 기존 모델과 같은 LSTM·게이트를 사용하고 실패하면 준비 부족으로 표시합니다. 최근 구간 대부분이 합성이므로 이 모델의 지표는 현장 예측 성능이 아닙니다.
4. 기본 화면은 확장 자료의 오늘 기준일을 사용합니다. 이력 API는 행별 출처를 제공하고 화면에 짧은 합성 자료 표시를 두고 접힌 자료·모델 정보와 문서에서 원본 관측 경계·출처를 확인할 수 있습니다. 중복된 이전 공급 재생 시작 UI는 제외하고 API·기록을 보존합니다. 현재 운영 시연은 ‘기본 상황 선택’·‘드리프트 시연 선택’으로 시작해 저장 자료 1일·21일·남은 자료 끝까지 진행을 사용합니다. 선택된 상황은 이어서 실행하며 처음부터 요청할 때만 새 검증 기록을 만듭니다.
5. 컨테이너 최초 기동에서 별도 확장 자료를 생성·검증·학습합니다. 동일 날짜 재시작은 저장 모델을 재사용합니다. 날짜가 바뀐 뒤 컨테이너를 다시 시작하면 새 확장 자료와 모델을 별도로 생성하며 이전 namespace를 삭제하지 않습니다. 실제 외부 API 수집 기능은 보존하고 이 기능과 혼동하지 않습니다.

검증은 재현성, 원본 값 보존, 미래 행 미생성, 출처 구간, 시간 분리, 별도 namespace 및 실제 HTTP의 오늘/내일 날짜·25개 구 준비 상태를 확인합니다. 전체 학습을 실행하지 않았다면 전체 완료라고 표시하지 않습니다.
