## 수정 설계와 완료 기준

기존자료/모델/실행증거/HAIC원본을 삭제하지 않고 호환가능한SQLite확장과선택필드를추가합니다. 모델품질게이트1.10/0.95/guard1.10은성공을만들기위해낮추지않습니다. 실측과합성registry·이력을분리합니다. 요청본문은운영로그에저장하지않습니다.

1. 자료/작업등록·날짜·history·monitor체크포인트·25/25준비·지문·MLflow추적 오류를 먼저수정하고 실제결함재현회귀검사를추가합니다.
2. 60초집계·최근300초창·최소20요청의p95/5xx/처리량과프로세스/모델준비율을분리합니다. 모델품질경보와서비스경보를구분합니다. 품질monitor조회와UI를연결합니다.
3. 합성지속변화자료를명시적으로생성하여업로드→학습/registry→HTTP기존버전→자동감지→workerfine-tune→후속30일→gate→실제HTTP새버전의하나의흐름을재현합니다. 실패시도도보존합니다. threshold완화·forcedpromotion·미래정답학습은금지합니다.
4. 공식6항목기획서에매핑·근거·API예시·실제화면을연결하고내부검수/설계문서를분리합니다. 제출형식/발표실행은미완료로유지합니다.
5. 전체회귀·실제TF/MLflow·HTTP200/422/409/503·화면·Docker재기동·25구정상준비를확인한후최종판정합니다.

기술근거: MLflow공식Client의get_model_version/run_id/log_metric/set_model_version_tag로등록후후보평가를동일run에기록합니다(https://mlflow.org/docs/latest/api_reference/python_api/mlflow.client.html). 실제지원버전은컨테이너설치본3.16.0에서검증합니다.

## 최종 결과

R1–R14의 코드·문서 수정을 완료했습니다. 전체 회귀 검사는 62개 통과·TensorFlow 선택 검사 1개 제외였으며, 실제 TensorFlow·모델 검사는 별도로 17개 통과했습니다. 원문은 evidence/reaudit-tests.txt와 reaudit-tensorflow.txt입니다.

실제 HTTP에서는 25개 구 준비·예측 200, 잘못된 입력 422, 중복 진행 409, 모델 미준비 503을 확인했습니다. Docker 재시작 후 영속 모델을 조회했습니다. 합성 자료의 전체 자동 흐름에서는 게이트를 유지한 채 v1→v2 교체와 실제 v2 응답을 확인했고, 첫 실패 시도도 보존했습니다. 서울 실측 90일 재생의 후보 거절·대기 결과와 구분합니다. 근거는 evidence/reaudit-final-http.json, reaudit-automatic-pipeline.json, reaudit-mlflow-evaluation.json입니다.

추가 화면 요구에 따라 종로구를 기본 선택으로 두고 25개 구 선택을 유지했습니다. 정상·수위 변화 재생, 실제 단계·로그·후보 평가·현재 서빙 버전을 연결했습니다. 이전 성공과 현재 후보 대기를 분리하고 모의 자료 표기를 검사했습니다. 파이프라인 회귀 검사 12개가 통과했습니다.
