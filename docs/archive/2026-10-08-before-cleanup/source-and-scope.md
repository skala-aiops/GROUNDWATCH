# 제공 코드와 팀 개발 범위

## 출처

사용자 제공 `project.zip`의 HAIC 모델 서빙·AIOps 스켈레톤이 기반입니다. 제공 README의 안내는 “학습 목적으로만 사용”이며 문의처는 architect@sk.com, audit@korea.ac.kr, 임성열 Ph.D.입니다. 제공 코드 자체를 팀 독자 구현 성과로 표기하지 않습니다. 원본 ZIP과 기존 로컬 백업은 보존했습니다.

## 이전 기반 코드 정리

- 실습 빈칸을 채우고 Day별 안내·빈칸 질문·장황한 학습용 주석을 제거했습니다.
- 기존 샘플 예측·드리프트 감지·재학습 흐름을 연결했습니다.
- MLflow 등록 URI·실제 모델 버전 표시·승격 뒤 캐시 갱신을 보완했습니다.
- 루트 Docker Compose와 최초 초기화·지속 볼륨·healthcheck를 구성했습니다.
- 파드별 브랜치·한국어 커밋·PR 없는 통합·AI 공용 지침을 마련했습니다.

## 이후 GroundWatch 도메인 구현

사용자의 전체 구현 요청에 따라 `groundwater_*` 모듈, 공식 자료 정규화·구별 학습·실제 registry/cache·영속 작업·재생·운영 이벤트와 대시보드를 추가했습니다. HAIC 샘플 데이터를 지하수 자료로 이름만 바꿔 사용하지 않습니다. 서울시 공식 관측자료와 고정 25개 관측소는 `../data/README.md`, 현재 실행 결과는 `../evidence/README.md`를 확인합니다. 아래 샘플 파일은 원본 출처·회귀 기록 보존용이며 현재 앱에 등록하지 않습니다. 이 세션에서 AI가 구현한 범위를 특정 팀원의 직접 작성 성과로 자동 귀속하지 않습니다.

## 보존한 HAIC 샘플의 한계

- 보존한 HAIC 샘플의 입력은 `Date,Close,Volume`, 모델은 `HAIC_Predictor`, RMSE 임계값은 샘플 기준 4입니다. 실제 지하수위 기준으로 검증된 값이 아닙니다.
- 배치 시뮬레이션은 감지 신호를 주입합니다. 재학습은 요청의 가격 배열이 아니라 **최근 업로드한 CSV의 마지막 41행**을 사용합니다. 주입한 분포에 적응했다는 검증으로 해석하지 않습니다.
- 최근 41행에서는 학습 16개·평가 5개 시퀀스로 나뉘므로 일반화 성능의 근거로 부족합니다.
- 시뮬레이션의 정상·변화 배치는 무작위이며, 이름만으로 판정 결과를 보장하지 않습니다. 실제 RMSE와 판정으로 확인합니다.
- 보존한 HAIC 샘플은 실행 중 모델 캐시·예측 기록을 단일 프로세스 메모리에 둡니다. GroundWatch는 별도 영속 SQLite 작업·예측 이력과 MLflow 모델을 사용합니다. 현재 구성은 로컬 단일 서버이며 현장 운영 보안 검증을 완료한 서비스가 아닙니다.

## API 전환 범위

2026-10-07 사용자 위임으로 실제 API 전환을 설계·구현했으나 최신 실측 원천과 승인 매핑 조건은 확보하지 못했습니다. [API 전환 조사](api-transition-redesign.md)는 검토 이력입니다. 기존 공식 HTML 기반 과거 CSV와 외부 API 원천은 별도 관측 DB·snapshot·모델 namespace로 관리하며, API 경로는 현재 기본 화면의 자료 공급원이 아닙니다. 기존 25개 역사자료 대표 명세를 API 매핑 승인 근거로 쓰지 않습니다.

별도 표시 달력을 썼던 이전 공급 도구의 API·기록은 [공급 시뮬레이션 설계](supply-simulation-design.md)에 보존합니다. 중복 시작 UI는 제외했으며 현재 시연 사용법은 [화면 사용법](demo.md)을 따릅니다. 기본 화면의 현재 날짜 예측과 혼동하지 않습니다. 원래 사업기획 PDF의 단일 관측소·합성 756일·cm/강수 10배·API 제외 항목은 현행 확정 설계가 아닙니다.

## 2026-10-08 과제용 합성 확장 추가

사용자 요청으로 `data/current_extension.py`와 별도 현재 날짜 자료·모델 흐름을 추가했습니다. 교수자 시뮬레이션 허용은 사용자 전달 근거이며 최신 실측 확보를 뜻하지 않습니다. 기존 공식 자료는 변경하지 않고 합성 행의 `origin`과 전체 `synthetic` namespace로 격리합니다. 현재 화면은 실제 달력 오늘→내일 예측을 표시하며 출처를 확인할 수 있게 합니다. 기존 실측 평가와 교수자 원본 코드는 보존합니다. [설계](current-extension-design.md)와 [실제 HTTP 검증](../../../evidence/current-extension-http.json)을 확인합니다.
