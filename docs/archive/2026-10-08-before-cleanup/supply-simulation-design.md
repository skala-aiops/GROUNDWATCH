# 실시간 자료 공급 시뮬레이션 설계

2026-10-07 구현한 과거 자료 순차 공급 도구의 설계 기록입니다. 이 도구의 중복 시작 UI는 2026-10-08 정리에서 제외했으며 API·기록·이전 검증 기록 조회를 보존합니다. 기본 화면의 자료 공급 경로가 아닙니다. 현재 기본 경로는 [오늘 기준 자료 확장 설계](current-extension-design.md)를 따릅니다. 아래의 별도 시연 시계는 원관측 날짜를 바꾸지 않고 과거 운영 과정을 재현하기 위한 것이며 실제 최신 관측이 아닙니다.

## 범위와 흐름

공식 과거 자료·잔차 LSTM·기존 재생 worker·MLflow·SQLite를 재사용합니다. 새 세션을 만들고 학습·검증·테스트 이후 재생 시작일을 원관측 기준일로 삼습니다. 시연 시작일은 서울 오늘로 별도 저장합니다. 관측소별 초기 검증 모델을 복사할 수 있으면 재사용하고, 없으면 기존 초기 학습을 실행합니다. 25개 준비 전 진행하지 않습니다.

원관측 t일까지 입력 → t+1 예측 저장 → 사용자의 하루 공급 요청 → 원관측 t+1 정답 공개·오차 감시·필요시 재학습 → 시연 시계 하루 진행 → 다음 날 예측을 조회합니다. 후보30일 평가·게이트·실패 시 기존 유지·롤백 정책은 바꾸지 않습니다. 정상 공식 자료로 자동 승격이 일어난다고 보장하지 않습니다.

## 시간과 저장 계약

POST /api/v1/replays에 선택 presentation_start_date(YYYY-MM-DD)를 추가합니다. 해당 필드가 있으면 공급 시뮬레이션이며 scenario=historical만 허용합니다. 기존 as_of/start_date/end_date와 관측 date·forecast_date는 원자료 달력입니다. 표시 시계는 presentation_start_date + (as_of-start_date)이며 모델 입력·scaler·학습 경계에 넣지 않습니다.

forecasts와 pipeline 응답은 simulation 객체(enabled, presentation_as_of, presentation_forecast_date, source_as_of, source_forecast_date, elapsed_days)를 추가합니다. 예측 행은 presentation_observed_date와 presentation_forecast_date를 병기합니다. history는 실제 date를 보존하고 presentation_date를 추가합니다. 시계 다음 날의 저장 예측은 관측·강수 null인 행으로 표시할 수 있으나 아직 공개하지 않은 정답은 포함하지 않습니다.

replay UUID namespace로 모델·예측·정답·이벤트를 격리합니다. 기존 JSON 객체에 메타데이터를 더하므로 DB 테이블 교체나 기존 자료 날짜 변경은 필요 없습니다. 생성 시 저장한 시연 시작일은 재시작해도 유지됩니다. 시뮬레이션에서 advance는 days=1만 허용하고 미래 기준일 조회를 차단합니다. 이는 모델 평가 경로의 시간 분리이며 전체 원자료를 보유하지 않는다는 뜻은 아닙니다.

## 당시 화면 설계 (현재 시작 UI 제외)

아래는 2026-10-07 당시 화면 설계입니다. 현재 사용 순서는 [화면 사용법](demo.md)을 따릅니다. 메인 상단에는 작은 시연 환경 표시·시연 날짜를 두고, 운영 화면에 시작·하루 자료 공급 버튼과 준비·작업 상태·두 시계를 표시합니다. 전체 표·상세 메타에는 시연 날짜와 원관측일을 병기합니다. 차트는 원자료 날짜를 유지하며 다음 날의 예측만 있는 점에는 정답이 없습니다. 고정 문구는 ‘실시간 공급 시뮬레이션 · 실제 오늘의 예측 아님’입니다. 기존 과거 조회·정상/변화 재생·서버 API 실험은 보존합니다.

## 완료 기준

단위·통합 테스트로 날짜 대응·원본 날짜 불변·새 namespace·미래 입력 차단·하루 단위 제한·정답 전후 공개·영속성을 확인합니다. 실제 Docker HTTP에서 새 공식 자료 세션 초기화→25개 예측→하루 공급→원관측/시연 날짜 하루 전진을 확인하고, 브라우저 전체·상세 화면을 검수합니다. 기존 과거25개 예측과 전체 회귀 테스트도 확인합니다. 최신 실제 자료 연결·현장 성능·실제 발표/제출 완료는 별도입니다.

2026-10-07 사용자 전달 교수자 허용: 시뮬레이션 데이터를 만들어 과제를 진행할 수 있습니다. 따라서 실제 판매 준비 기준을 이번 완료 조건으로 요구하지 않으며 데이터 공급 시뮬레이션과 실제 모델 운영의 구분을 팀 문서·발표에 남깁니다.
