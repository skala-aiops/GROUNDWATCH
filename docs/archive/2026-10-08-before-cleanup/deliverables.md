# GroundWatch 산출물 안내

- [기획서](../../../proposal.md): 교수자 가이드의6항목, 공공기관 사용자·운영 정책·구조·API·실제 화면입니다.
- [팀 로직 설명](team-logic-guide.md): 교수님 원본과 현재 구조·전체 흐름 비교입니다.
- [서비스 정리 설계](public-agency-service-review.md): 과제 필수 구분과 화면·표현·기능 정리 기준입니다.
- 이전 설계와 검수 기록은 docs/archive에 보존합니다.
- [실행 증거](../../../evidence/records/2026-10-08.md): 공식 자료와 합성 검증을 구분한 원문·화면·지표입니다.
- [발표·시연](demo.md): 20분 이내 진행과 실패 시 보존된 증거를 사용하는 순서입니다.
- [운영 정책](operations.md), [API 계약](../../contracts.md), [팀 협업 규칙](../../../AGENTS.md)을 함께 관리합니다.

발표·기획 자료 위치는 [발표·기획 자료 안내](../../../output/skill-comparison/README.md)와 output/AIOps_조별 과제_광주_3반_GroundWatch.zip입니다. 편집형 발표 2종(26·25장), 이미지형 발표 1종(14장), 공통 기획서를 관리합니다. 각 기획서 복사본은 같은 내용이며, 최신 코드 반영·렌더링·묶음 검수 결과는 실행 증거를 기준으로 확인합니다.

파일명과 마지막 팀원 페이지 형식은 교수자 전달 지시를 반영했습니다. 사진은 사용자 요청에 따라 자리만 마련했습니다. 실제 발표·제출, 제출 마감, B2G 방향의 B2B 필수 조건 인정 여부는 확인되지 않았습니다.

output/pdf 및 output/pdf/archive의 기존 PDF와 output/archive의 이전 발표본은 과거 기록입니다. 최신 제출본으로 사용하지 않습니다. 원본 자료·소스·검증 증거는 삭제하지 않습니다. 이전 공급 시연 시작 UI는 제외했으며 API·실행 기록을 보존합니다. 현재 동선은 관측소 현황 → 관측소 상세 → 모델 관리 · 시연입니다. 공급 시연의 기존 설계는 [설계 문서](supply-simulation-design.md), 현재 기본 경로는 [합성 확장 설계](current-extension-design.md)를 따릅니다.

발표 디자인은 인터넷 공식 가이드와 템플릿 사례를 참고해 화이트·코발트 / 화이트·블랙 / 화이트·블랙 세 방향으로 다시 제작했습니다. 상세 색상·서체·배치와 프롬프트는 각 스킬 폴더의 디자인_프롬프트.md, 비교는 output/skill-comparison/디자인_비교.md에 있습니다.
