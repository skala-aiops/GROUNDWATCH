# 화면 설계 방향

- 사용자는 구별 관측소를 확인하는 환경·시설 운영 담당자입니다. 다음 확인 대상과 자료의 기준일을 빠르게 찾도록 구성합니다.
- 공공 관측 업무의 기록부처럼 차분하고 정확한 인상을 유지합니다. 홍보 문구와 장식용 대형 숫자는 줄입니다.
- 왼쪽 탐색, 상단 조회 조건, 짧은 현황 띠, 관측소 표 순으로 배치합니다. 첫 화면에서 실제 구별 값을 확인할 수 있게 합니다.
- 한글 시스템 글꼴과 고정 폭 숫자를 사용하고 제목·설명·수치의 크기 차이를 절제합니다.
- 밝은 회색 바탕과 흰 표, 짙은 녹색으로 구성하고 황색·적색은 확인이 필요한 상태에만 사용합니다.
- 움직임은 선택과 처리 상태 전달에만 사용합니다. 조회 중에는 이전 범위의 값을 숨겨 혼동을 막습니다.
- 자료 구분·조회 날짜·마지막 관측일을 반복해서 확인할 수 있는 기록 중심 구성을 화면의 특징으로 삼습니다.

사용자 참고 화면 반영: 전체25구는 그대로 유지하고 상세·운영은 종로구를 기본 선택합니다. 작업을 실행하는 시나리오 버튼과7단계 실제 상태·후속정답 대기·기록을 운영 화면의 첫 내용으로 배치합니다. 단계가 실제로 완료되지 않으면 색만 바꾸거나 성공 문구를 표시하지 않습니다.

## API 일별 운영 반영

세 화면과 종로구 기본 선택을 유지합니다. 오늘 예측은 live 전용 조회, 과거 재생은 기존 계약을 사용합니다. 오늘 예측에서 검증되지 않은 API 자료를 과거값으로 채우지 않으며 그래프·모델·작업·이벤트·7단계도 출처를 분리합니다. 실제 관측일이 없으면 날짜는 빈값입니다.

공식 API 수집 패널은 진단용 이름·ASOS조건, 출처별 수신/유효/격리·최신 유효일·실패·재시도, 관측 revision/품질기록·입력준비0/25를 보여줍니다. 수집 작업 종료와 예측 적용을 구분합니다. 모델 품질 경보를 현장 위험 등급으로 표시하지 않습니다.
