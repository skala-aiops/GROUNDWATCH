# GroundWatch 발표 디자인 재설계

## 세 가지 방향

| 버전 | 색상 | 배치 방향 |
| --- | --- | --- |
| OpenAI | 화이트·검정·코발트 | 편집형 보고서: 비대칭 그리드, 얇은 구분선, 직접 라벨을 붙인 차트 |
| Anthropic | 화이트·블랙 | 기술 발표: 흰색 표지와 검은색 제목, 가로 구획, 큰 구성도와 화면 |
| codex-ppt | 화이트·블랙 | 단색 편집형: 큰 제목·수치, 단순 선 도식, 넓은 여백 |

공통으로 한 장에 핵심 주제 하나를 두고, 제목·본문·주석의 글자 크기를 일정하게 사용합니다. 장식용 아이콘과 반복되는 카드 배치는 줄입니다. 실제 화면은 편집형 자료에서 원본을 크게 표시하고, 이미지형 자료에서는 화면을 그럴듯하게 다시 만들지 않습니다. 수치·API·과제 필수 항목은 기존 검증 내용을 유지합니다.

## 참고한 공식 자료

- [Microsoft: PowerPoint design ideas](https://powerpoint.cloud.microsoft/create/en/blog/powerpoint-design-ideas/): 여백, 한 장의 핵심 메시지, 차트의 직접 라벨, 일관된 서체와 대비를 참고했습니다.
- [Microsoft: 효과적인 발표 작성](https://support.microsoft.com/en-us/powerpoint/tips-for-creating-and-delivering-an-effective-presentation): 멀리서 읽을 수 있는 서체와 실제 발표 크기 검수를 참고했습니다.
- [Beautiful.ai: 발표의 핵심 요소](https://www.beautiful.ai/blog/what-makes-a-good-presentation-8-key-elements): 글자 위계·색상 체계·의미 있는 시각 자료를 참고했습니다.
- [Beautiful.ai: AI에도 필요한 디자인 규칙](https://www.beautiful.ai/blog/ai-can-build-slides-fast--but-great-presentations-still-need-design-rules): 자동 생성 뒤 배치와 글자량을 다시 검수하는 기준을 참고했습니다.
- [Gamma: AI 발표 프롬프트 가이드](https://gamma.app/pl/explore/content/guides/the-ultimate-guide-to-ai-presentation-prompts-how-to-get-better-slides-from-gamma): 목표·청중·내용·톤·형식을 정하고 슬라이드별 프롬프트를 작성하는 방식을 참고했습니다.
- [Canva: 발표 템플릿](https://www.canva.com/presentations/templates/): 흑백 편집형, 비즈니스 블루, 크림색 미니멀 계열의 구성을 참고했습니다.

위 서비스의 디자인 원칙을 참고했으며, Canva·Gamma·Beautiful.ai 서비스에서 파일을 생성한 것은 아닙니다. 실제 제작 도구와 상세 프롬프트는 각 스킬 폴더의 디자인_프롬프트.md에 기록합니다.
