# GroundWatch 발표자료 디자인 프롬프트

## 대상과 목표
SKALA 4기 광주3반 5조의 모델 서빙·AIOps 과제 발표입니다. 한형준이 설명하고 교수자와 수강생이 듣습니다. 기술 목록보다 업무 문제, 데이터, 예측, 품질 감시, 재학습·후속 평가와 실제 실행 증거의 관계를 이해하도록 구성합니다. 본문 약 12~14분, 질의응답 약 3분으로 20분 이내입니다. 부록은 질문 시 사용합니다.

## 시각 방향
Swiss/editorial: 흰 종이와 검정 잉크, 코발트 강조를 사용합니다. 반복 카드 대신 비대칭 정렬, 얇은 구분선, 큰 수치와 식, 직접 읽히는 편집 가능한 차트를 배치합니다. 카드 구성은 사용자가 요청한 마지막 팀원 사진 자리에서만 사용합니다.

- 캔버스: 16:9, 1280×720
- 색상: 배경 #FAFAF7, 본문 #171A20, 강조 #2854D8, 사진 자리 #DDE5FF
- 글꼴: Apple SD Gothic Neo, 본문 20~26pt, 제목 약 32pt, 출처·한계 약 15pt
- 정렬: 좌우 여백 약64px, 제목 시작151px, 번호64px, 기준선113px
- 표지: 큰 GROUND / WATCH 타이포그래피와 작은 설명. 장식용 아이콘·그라디언트·발광 효과 제외
- 데이터: 핵심 숫자·단위를 가까이 배치하고 단위/출처/기간 유지
- 차트: 원자료 수치 기반 native bar chart, 편집 가능한 workbook 포함
- 아키텍처: 편집 가능한 글상자·연결선으로 실제 자료와 모델 흐름 표시
- 시연: 전체 현황, 관측소 상세, 운영을 각각 한 장씩. 실제 원본 캡처의 주요 영역만 확대하고 부분 확대 사실 표기. 사진이나 UI를 생성하지 않음
- 마지막: 6명 이름·확정 역할·편집 가능한 사진 자리, 사진은 추가 예정

## 사실 경계
서울 공식25개 관측소52,591행, 같은 HTML 날짜·수위·강수 결합, ASOS join 아님. 원자료 날짜와 수위 부호 보존. 공급 시뮬레이션과 실제 추론·worker 구분. 서울 실측 승격 없음과 격리 합성 실제v2 검증을 구분. warm 순차100회와 cold 측정을 SLA로 확대하지 않음. B2G와 B2B 과제 조건의 확인 필요를 남김.

## 작성 방식
공식 OpenAI presentations 스킬과 @oai/artifact-tool을 사용합니다. 편집 가능한 PPTX를 최종화한 뒤 bundled LibreOffice로 PDF를 렌더링하고 모든 페이지의 글자·배치·실제 캡처를 확인합니다. 원본 증거 이미지는 변경하지 않습니다. 개인별 세부 성과를 역할명만으로 추가하지 않습니다.

글꼴 호환성: 편집용 PPTX는 Apple SD Gothic Neo를 사용합니다. 해당 글꼴이 없는 Windows에서는 글꼴 대체로 줄바꿈이 달라질 수 있으므로 그대로 발표할 때는 함께 제공한 PDF를 사용할 수 있습니다.


같은 날짜의 입력 수위와 저장 예측을 소수 셋째 자리로 비교하며 높음은 해당 숫자·관측점 빨강, 낮음은 파랑입니다. 같거나 예측이 없으면 기본색이며 내일 예측은 주황입니다. 위험도·드리프트 판정과 구분합니다.
