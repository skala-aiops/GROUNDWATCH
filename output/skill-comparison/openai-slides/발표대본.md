## 2. 검토할 관측소와 예측의 신뢰도

대상은 공공기관의 지하수·지하안전 업무 담당자입니다. 관측 자료와 예측을 따로 확인하면 변화를 검토하기 어렵고 오차가 커진 예측을 계속 참고할 수 있습니다. 장애는 확인 업무를 중단시키고, 품질 저하는 판단 근거를 약하게 합니다. 도입 효과와 시간 절감은 아직 측정하지 않았습니다.

## 3. 다음 날 수위와 모델 품질을 함께 확인

## 4. 서울시 공식 과거 관측자료

자료는 서울시 공개 관측 페이지의 과거 기록입니다. 날짜 배열에 대응하는 수위와 강수를 같은 인덱스로 결합했습니다. 관측소 ID와 날짜로 중복을 확인하고 manifest로 구와 단위를 연결합니다. 현재 학습 데이터는 기상청 ASOS를 결합한 자료가 아닙니다. 결측 강수를 0으로 채우거나 수위 부호를 반전하지 않았습니다.

## 6. 미래 정답을 분리한 시간 순서

각 관측소의 연속 20일 수위와 강수가 입력이고 다음 날 수위가 정답입니다. 날짜 공백을 이어 붙이지 않습니다. 시간순으로 학습 최대 730표본, 검증 60일, 테스트 60일을 분리하고 이후 90일을 재생합니다. 정규화는 학습 구간에서만 계산합니다. 재생에서는 하루씩 정답을 공개해 미래 정보를 차단했습니다.

## 7. 마지막 수위에 변화량을 더하는 모델

지하수위 변화가 작아 마지막 수위를 그대로 예측하는 persistence가 중요한 비교 기준입니다. LSTM이 절대수위 전체를 예측하는 대신 마지막 관측에 변화량을 더하도록 구성했습니다. 최종 25개 모델이 초기 게이트를 통과했습니다. 이 조건은 persistence보다 10% 이상 나빠지지 않는다는 뜻이며 모든 관측소에서 더 좋다는 뜻은 아닙니다.

## 8. 품질 감시와 모델 교체 조건

21일 RMSE가 검증 rolling RMSE P95의 1.5배를 두 번 연속 넘으면 이벤트와 재학습 작업을 등록합니다. 21일 창과 연속 조건은 일별 잡음과 반복 작업을 줄이려는 설정입니다. 최근 41일로 학습한 후보를 이후 새 정답 30일 동안 기존 모델과 비교합니다. 5% 개선은 작은 변동에 따른 교체를 줄이고, 과거 오차 110% 제한은 이전 품질의 악화를 막는 조건입니다. 로딩 검사까지 통과해야 교체하며 실패하면 기존 모델을 유지합니다. 이 숫자는 과제 실험 설정이며 안전 기준은 아닙니다. 데이터 드리프트는 입력 분포 변화, 컨셉 드리프트는 입력과 정답 관계 변화입니다. 현재는 RMSE 오차 경보를 관찰하며 원인을 통계적으로 구분 확정하지 않습니다.

## 13. 03  모델 관리 · 시연

합성 확장 모델 첫 25개 학습 결과에서 각 구 RMSE의 단순 평균을 계산했습니다. 검증 LSTM 0.016396, persistence 0.016561이며 테스트 0.020471, 0.020544입니다. 검증 2026년 3월 13일부터 5월 11일까지 60일, 테스트 5월 12일부터 7월 10일까지 60일입니다. 대부분 합성 구간이고 완만한 생성식의 영향을 받아 기존 실측 성능과 직접 비교하거나 현장 성능으로 해석할 수 없습니다. 이후 종로구 수동 학습 v2는 이 최초 25개 집계와 구분합니다.
