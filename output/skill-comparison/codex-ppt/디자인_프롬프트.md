# 흰색·검정 단색 재설계

사용자 피드백에 따라 이전 아이보리·숲색·러스트, 종이 질감과 삽화를 전부 제거했습니다. 배경 #FFFFFF, 본문 #111111, 보조 #666666, 선 #E5E5E5. 산세리프 한국어, 큰 짧은 제목, 22–26pt 상당 본문, 엄격한 정렬·여백으로 구성합니다.

공통 프롬프트: Pure solid white background. Neutral black and gray only. Crisp Korean sans-serif typography, generous white space, precise aligned grid. No texture, shadows, gradients, 3D, illustrations, decorative icons or rounded card grids. Preserve factual values and limitations. Simplify duplicated wording. Safe margins, no cropping.

각 장은 기존 built-in 생성 이미지를 같은 이미지 도구로 편집했습니다. 사용자와 부모 에이전트의 명시적 지시에 따라 이번 전체 단색 편집은 새 worker 없이 주 에이전트가 직접 병렬 처리했습니다. 초기 장별 worker provenance는 임시 보존본에 남겼으며 최종 편집 provenance는 slide_jobs.json에 기록합니다.

디자인 참고는 Microsoft PowerPoint, Beautiful.ai의 단일 메시지·여백·읽기 쉬운 글자 계층 원칙입니다. Canva나 Gamma 서비스에서 생성한 결과가 아닙니다.

- https://powerpoint.cloud.microsoft/create/en/blog/powerpoint-design-ideas/
- https://www.beautiful.ai/blog/what-makes-a-good-presentation-8-key-elements
- https://www.canva.com/presentations/templates/

도식은 개념 설명입니다. 실제 원본 동작 화면은 공통 기획서 PDF에서 확인합니다. 최종 슬라이드는 전체 이미지이므로 글자·도형을 개별 편집할 수 없습니다.


## 2026-10-08 화면 정리 반영
업무 담당자: 관측소 검색 → 상세 예측값·최근 30일 비교. 운영자: 모델 관리 · 시연 → 기본/수위 변화 시연 → 저장 자료 1일·21일 진행. 로딩·완료 일수·재학습·평가 대기·실패를 구분하고 복귀 사유 입력은 제거했습니다. 실제 최신 관측 확보로 설명하지 않습니다. CSV 화면 파일 선택은 미검증이며 HTTP 등록 근거와 구분합니다.


같은 날짜의 입력 수위와 저장된 예측이 모두 있으면 소수 셋째 자리로 비교합니다. 입력이 더 높으면 해당 숫자와 관측점만 빨강, 낮으면 파랑이며 같거나 비교 예측이 없으면 기본색입니다. 내일 예측은 주황을 유지합니다. 이 색은 위험도나 드리프트 판정이 아닙니다.
