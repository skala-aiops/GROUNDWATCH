## Slide 6: 시간 순서와 입력 품질을 지킵니다
- 학습 최대 730개 유효 구간 → 검증 60일 → 테스트 60일

- 테스트는 개발 중 확인 · 외부 평가와 구분

## Slide 7: 예측과 운영을 하나의 흐름으로
- 자료 업로드 → 학습 → MLflow 모델 관리

- worker: 품질 감지 → 재학습 → 재검증
- SQLite에 예측·작업·이력 보존

## Slide 8: 품질 저하를 감지해도 바로 바꾸지 않습니다
- 21일 RMSE > 검증 rolling P95 × 1.5 · 연속 2회

- 5% 이상 개선 + 과거 성능 110% 이내 + 로드 검사
- 검증 실패는 기존 모델 유지 · 재학습 간격 21일
