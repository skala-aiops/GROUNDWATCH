# GroundWatch 발표자료

14장 · 전체 장 이미지와 발표자 노트. 발표자는 한형준입니다. PPTX와 PDF, 발표대본(또는 speech.md)을 사용합니다. 마지막 장의 사진 틀에 실제 팀원 사진을 추가할 수 있습니다.

2026-10-08 현재 코드 기준으로 관측소 현황 → 관측소 상세 → 모델 관리 · 시연 순서를 반영했습니다. 예측 날짜·값과 최근 30일을 먼저 확인하고, 운영자는 저장 자료 진행과 재학습 상태를 확인합니다. 중복 공급 UI는 제거했으며 기존 API와 실행 근거는 보존했습니다. 복귀 사유 입력은 없습니다.

최근 자료는 과제용 합성 확장이며 실제 최신 관측이 아닙니다. CSV 등록 HTTP 검증과 브라우저 파일 선택 미검증을 구분합니다. 기획서/는 공통 기획서의 복사본입니다.


같은 날짜의 입력 수위와 저장된 예측이 모두 있으면 소수 셋째 자리로 비교합니다. 입력이 더 높으면 해당 숫자와 관측점만 빨강, 낮으면 파랑이며 같거나 비교 예측이 없으면 기본색입니다. 내일 예측은 주황을 유지합니다. 이 색은 위험도나 드리프트 판정이 아닙니다.
