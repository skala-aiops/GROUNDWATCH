# GroundWatch 디자인 프롬프트 — Anthropic PPTX

## 목적과 청중
SKALA 4기 광주3반 5조의 모델 서빙·AIOps 과제 발표입니다. 교수자와 동료 수강생에게 문제, 실제 데이터 연결, 모델 품질 관리와 실행 증거를 20분 안에 설명합니다. 발표는 한형준이 맡습니다.

## 시각 방향
Contemporary research keynote. 흰색 배경과 검은색 본문을 사용한 차분한 연구 발표입니다. 기존 녹색 덱을 재사용하지 않고 레이아웃부터 새로 작성합니다.

- 검정 #111111, 흰색 #FFFFFF, 보조 회색 #666666, 옅은 회색 #F0F0F0
- 한글 폰트 Arial Unicode MS. 제목 36pt, 본문 20–27pt, 출처 12pt. 표는 부록에만 17pt.
- 16:9, 가장자리 여백 0.65인치 이상. 짧은 제목, 계층과 여백을 유지합니다.
- 수평 band, 중앙 수식, 한 가지 큰 수치, 직접 라벨을 단 native chart를 교차 사용합니다.
- 데이터 표와 차트, 모델 구성도는 편집 가능한 PowerPoint 객체로 제작합니다.
- 동일한 3카드 레이아웃을 반복하지 않습니다. 장식 아이콘, 네온, 그라데이션, 그림자, 둥근 카드 나열을 쓰지 않습니다.
- 시연은 전체 현황, 관측소 상세, 모델 품질 운영 화면 각각의 전용 페이지로 구성합니다. 원본 캡처의 핵심 영역만 확대하며 원본 이미지를 변경하거나 가짜 UI를 만들지 않습니다.
- 마지막 장에 확정된 6명 역할과 사진 자리만 둡니다. 사진을 생성하지 않습니다.

## 내용과 근거
통합가이드 필수 6항목, team/proposal.md, docs/team-logic-guide.md, docs/contracts.md, evidence/README.md를 사용합니다. 과거 공식 관측, 오늘까지의 합성 확장, 기존 공급 재생, 별도 합성 자동 승격을 구분합니다. 기존 원관측과 모델·평가를 보존하고 합성 확장은 별도 namespace에서 학습합니다. 싱크홀 확률·현장 위험 성능·운영 SLA를 주장하지 않습니다. ASOS를 현재 입력으로 설명하지 않습니다. B2G와 B2B 과제 조건은 확인 필요로 남깁니다.

## 제작·검수
PptxGenJS 독립 제작, bundled LibreOffice PDF 변환. 본문 18장, 질문 대응 부록 6장, 마지막 팀원 소개 1장입니다. 오늘 기준 합성 확장 모델 25개 학습 완료와 2026-10-08 입력·10-09 예측은 current-extension-http.json의 실제 HTTP 증거를 확인해 표시했습니다. 본문 약 14분과 시연 캡처 설명 약 3분, 질문 약 3분을 권장합니다. 모든 25개 슬라이드를 1600px로 렌더해 개별 확인했습니다. 원본 캡처와 공통 기획서는 보존합니다.

사용자 최종 선택: 흰색 배경과 검은색 본문을 기본으로 통일했습니다. 보라색은 제거하고 보조 설명·구분선·사진 자리만 중립 회색을 사용합니다. 표지도 흰 배경입니다. 원본 증빙 화면의 색상은 보존합니다.
